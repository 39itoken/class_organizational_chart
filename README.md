# 学級組織図

Googleスプレッドシートで、1A〜3Cの9学級について前期・後期の学級組織図を管理・表示するプロジェクトです。

## 完成版・動作確認用スプレッドシート

- [学級組織図_動作テスト（現時点の完成版）](https://docs.google.com/spreadsheets/d/1gKwdtidZSJmHVUCNLjx-pGylnb0BhFTYbhD-r_1v7E4/edit)

## 現在の仕様

- 対象学級：1A / 1B / 1C / 2A / 2B / 2C / 3A / 3B / 3C
- 学期：前期 / 後期
- 各学級シートで前期・後期を入力
- 共通組織図で「学級」「学期」を選択して表示
- 数式ベースで動作し、現段階ではGASを使用しない
- 後期ブロックも前期と同じ配置計算が動作するよう修正済み

## 動作確認用ダミーデータ

各学級40名で検証。

- 班：6班
- 班長：6名
- 学級執行部：6名
- 委員会：6種類、各2名
- 係：役職者と兼務しない22名に割当

### 班長の配置パターン

- A組：学級執行部6名が班長を兼務
- B組：各委員会の2名のうち1名が班長を兼務（計6名）
- C組：班長6名を兼務ではなく、学級執行部欄の独立役職として配置

### 係

係は班長・委員会・学級執行部と兼務しない。

- 窓係
- 黒板係
- 笑顔係
- 朝の会係
- 水やり係
- 机係
- あゆみ係
- ロッカー係り

## 検証状況

9学級 × 前期・後期の18パターンを対象に、学級・学期の切替、タイトル、氏名表示、後期側の配置計算を確認。
係については全18パターンで他役職との兼務0名を確認済み。

## 本番ファイル

本番データにはダミーデータを投入せず、動作テスト用コピーで検証しています。
